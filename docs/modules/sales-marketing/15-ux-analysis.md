# 15 — تحليل تجربة المستخدم (UX Analysis) — وحدة SLM

> قراءة تقييمية للأنماط التفاعلية الموثقة — الوحدة الأقرب لـ**منتج CRM مكتب-مبيعات كلاسيكي**: أدوات طاولة مفاوضات + تنظيم يومي شخصي + إنتاج تقارير محدود.

---

## 1. الأنماط التفاعلية الموثقة

### 1.1 أداة 360° — أول "Customer Single View" في المشروع
- **Sales Manager Tool**: اختيار شركة → 10 عروض مسطحة + Hotel Position متعدد الأعماق (يومي→ساعي→غد→تفصيلي→سنوي).
- نقاط القوة: تجميع كل ما يخص العميل في شاشة واحدة (حجوزات/نزلاء/إيراد/مديونية/زيارات) — **نمط dashboard ما قبل عصر الـdashboards**.
- الثغرات: عروض بالتبويب تنقر يدوياً؛ لا تصدير للأداة نفسها؛ بيانات بعض العروض **قراءة فقط** (General Info) بينما نظيراتها قابلة للإضافة (Sales Activity زر New).

### 1.2 الاستدعاء من سياق العمل (النمط الذهبي الوحيد)
- **Browse Hotel Profile يُستدعى من شاشة الحجز** (LUK §4) — الملف التسويقي (outlets/banquets/picnic) **بيانات بيع حية أمام العميل** — أفضل ممارسة UX في الوحدة: الخدمة حيث تُستهلك.

### 1.3 جلسة مستقلة داخل جلسة
- Executive Planner: شاشة user/password **داخل** التطبيق + logout صريح — نمط "غرفة شخصية" (يوميات المندوب) — مقبول لأمان بيانات المنافسة بين مندوبين، لكنه كسر تدفق (خروج من سياق النظام كله).

### 1.4 لوحة الساعات اليدوية
- Things To Do: شبكة 7am–8pm، نقر خانة ساعة = إدخال مهمة — **مخطط يومي تشغيلي** قابل للترجمة الحديثة مباشرة (Frappe Calendar day view) بفارق جودة هائل.

### 1.5 التحرير الجماعي الخطير
- Update Company Profile: Old Value → New Value بلا معاينة أثر ولا تأكيد موثق — **أخطر تفعيل UX في الوحدة** (R-SM-2: يجب preview + dry-run).

## 2. إيقاع العمل اليومي المفترض (Persona: Sales Executive)

```
صباحاً:  Executive Planner (دخول) → Appointments اليوم + Things To Do
         → In-house Guests (ضيوف شركاتي الحاليون — فرص بيع!)
ميدانياً: Daily Sales Call (إدخال الزيارة + المتابعة التالية)
مكتباً:  Browse Company (فحص Credit Limit قبل مكالمة تحصيل)
         → Sales Manager Tool (استعداد لمقابلة: كل شيء عن الشركة)
عصراً:   Entertainment/Gift Entry (توثيق مصروف الضيافة)
أسبوعياً: Follow-up/Schedule Report (خط الزمن القادم)
شهرياً:  Sales Performance (Budget) (مواجهة الانحراف!)
```

## 3. تقييم نقاط الاحتكاك (Friction Points)

| النقطة | الوثيقة | الأثر | المعالجة المقترحة |
|---|---|---|---|
| قيود تقارير قصيرة (شهر/31يوم/نفس الشهر) | REP §2/§15/§19 | تحليل يدوي متكرر | R-SM-5: رفع القيود (لا خسارة وظيفية) |
| Outlook + Word خارجيان | REP §12 | انقطاع سياق + اعتماد سطح مكتب | F-SM-5: بريد منصة + قوالب |
| أزرار صور مخفية (النص يشير لأزرار بلا تسميات — "Click [صورة]") | كل الملفات | الأزرار في الأصل أيقونات بلا tooltips موثقة | تسمية قياسية عند إعادة البناء |
| تكرار تقرير الأداء مرتين | REP §7/§19 | ارتباك المستخدم | R-SM-3: دمج |
| لاقياس لأثر المهرجانات | SLT §2 | إدخال بلا تعلم | ربط بتقارير POS/BNQ (F-SM-6) |
| عروض Planner بلا تنبيهات | SLT §9 | الاعتماد على الفحص اليدوي | إشعارات (Notification) عند الموعد/المتابعة |

## 4. نقاط القوة الوظيفية (تُحفظ في إعادة البناء)

1. **قائمة الفلترة الائتمانية** (Browse Company by Credit Limit range) — ذكاء ميداني يُحفظ حرفياً.
2. **فرز المواعيد الرباعي** (Company/zip/City/State) — زوايا تنظيم يوم ميداني فعلي.
3. **Show Past Reservation / Cancelled / No Show** معاً في عرض واحد — رؤية صادقة لتاريخ الشركة.
4. **قناة الحملة المكتملة** (Birthday قائمة → Letters بريد بمرفقات → Labels طباعة) — سلسلة تسويقية كاملة تُعاد بنمط حديث واحد.
5. **تخصيص أعمدة Company Contribution** (column #/heading/options) — بذرة report-builder تُطور.

## 5. ملاحظات RTL/تعريب (للتنفيذ العربي-أولاً)

| البند | القرار |
|---|---|
| أسماء العروض العشرة للأداة | ترجمة معيارية (نظرة عامة/نشاط المبيعات/الضيافة/الأسعار المتفاوضة/المرفقات/الحجوزات/النزلاء الحاليون/الإيراد/المستحقات/زيارات الضيوف) |
| "Picnic Spots" | **أماكن النزهة القريبة** — مصطلح سياقي يحتاج صياغة تسويقية عربية (وجهات قريبة) |
| Watch List | **قائمة المراقبة** — مع دلالة "حتى تاريخ محدد" |
| Over Booking | **الحجز الفائق** (متسق مع FO) |
| Things To Do Important/Normal | **مهم/عادي** |
| التقويم 7am–8pm | مراجعة ساعات عمل إقليمية (توقيت العمل الخليجي قد يمتد مساءً) |

## 6. حكم نهائي مختصر

الوحدة **مصممة لعقل مندوب مبيعات ميداني** (أدوات سريعة + بيانات مركزية + يوم منظم) أكثر منها نظام إدارة تسويق شامل — أكبر استثمار UX عند إعادة البناء يذهب لـ: (1) توحيد الأداة 360° في dashboard حقيقي، (2) تحويل Planner لتقويم منصة بإشعارات، (3) قمع خطر التحديث الجماعي، (4) سلسلة الحملات البريدية المنصة-داخلية.
