# 18 — معايير القبول (Acceptance Criteria) — وحدة System Setup

> 8 مجموعات معايير + خطة Smoke Test. تُقرأ مع `16-erpnext-mapping.md` (القرارات F-SYS-1..12).

---

## AC-1 — إدارة المستخدمين والمصادقة

- [ ] إنشاء مستخدم بكل الحقول الموثقة (user ≤10, name ≤40, short_name ≤10, designation, group, password policy, status).
- [ ] توليد كلمة مرور أولية آلياً **بلا عرض نصي في أي جدول** (F-SYS-6) — تسليم برابط/عرض مرة واحدة.
- [ ] انتهاء صلاحية كلمة المرور (أيام) يفرض التغيير — **يغلق UNK-023 بقرار موثق** (سلوك: إلزام تغيير عند أول دخول).
- [ ] تعطيل مستخدم يمنع الدخول فوراً؛ إعادة التنشيط تعمل من تبويب "غير النشطين".
- [ ] تعديل بيانات المستخدم يعرض تنبيه "راجع الصلاحيات" (مثل prompt الأصل ص11).
- [ ] يوجد مسار استرداد مشرف (Frappe Administrator مستقل) — يغلق E-SYS-01/02.

## AC-2 — الصلاحيات (SYS المظلة + الخاصة)

- [ ] Group (Role) يُمنح صلاحيات، ومستخدم يرثها؛ ومستخدم بلا مجموعة يُدار مباشرة.
- [ ] Supervisor ≡ دور بوصول كامل — **لا تظهر له شاشات منح الصلاحيات الفردية** (مطابقة سلوك الأصل: "only for those who are not Supervisors").
- [ ] صلاحيات create/write/delete تعمل على مستوى DocType بقاعدة F-SYS-9.
- [ ] حجب تقرير (Spool/Export مفهوماً كـ print/export) يسري فوراً لكل تقارير الوحدة المستهدفة.
- [ ] حجب منفذ (POS Restrict Outlet) عبر User Permissions يعمل blocklist أو أقوى.
- [ ] تقرير "List Users Access" يطابق واقع الصلاحيات فعلياً (اختبار عكسي).

## AC-3 — المرجعيات العامة (Ch3)

- [ ] كل كيان من الـ 18 قابل للإنشاء بحقوله الموثقة (أنظر 01-master-data) **مع التحقق بالأطوال** (V-SYS-07..22).
- [ ] Applicable From يرفض التاريخ الماضي؛ ويسري فعلياً في تاريخه (اختبار مع قيمة مستقبلية + تاريخ سابق يوم).
- [ ] تعديل كيان مجمد يرفض الحقول المحمية: Departments (الاسم) مثلاً — ويسمح بالحالة فقط؛ الاستثناءات الثلاثة تعمل (Property: address؛ Designation: guest_type؛ Currency: division_method).
- [ ] Passive يختفي من قوائم الاختيار افتراضياً ويظهر مع "إظهار الكل".

## AC-4 — العملات وأسعار الصرف

- [ ] عملة أجنبية بـ Standard Rate + Decimal Length 0-3 + Text before/after تعمل في الطباعة/العرض.
- [ ] Division Method يغير التحويل (اختبار مثال الدليل: 5000 USD × 49 = 245,000 أو ÷ 49 ≈ 102.04).
- [ ] أسعار صرف متعددة زمنياً؛ **قيد ≤4 مُسقط بموجب F-SYS-12** لكن الإصدارية الزمنية سارية؛ AR يثبت سعر تاريخ الفاتورة (اختبار تكاملي مع ACR).
- [ ] تعديل Division Method لعملة مستهلكة يعرض تحذير أثر (E-SYS-09).

## AC-5 — محرك الضرائب

- [ ] Tax Code بـ Applicable To يظهر في الوحدات الأربع المستهدفة فقط.
- [ ] Slab تراكمي: 750 على شرائح الدليل (0-500=2%، 500.01-1500=3.5%) = **26.25**.
- [ ] Slab غير تراكمي على نفس القيم = **18.75** (500×2% + 250×3.5%).
- [ ] Structure بنوع Percentage وAmount وSlab يعمل؛ On Discounted Value يخفض الوعاء بالخصم؛ **On Tax يضري ضريبة سابقة بترتيب Tax#**.
- [ ] شرائح Slab متصلة آلياً (amount_from = amount_to السابق).

## AC-6 — Round-off والتقريب

- [ ] أمثلة الدليل الأربعة تنطق بالضبط: 1000.49/1.00 → None=1000.49 · Lower=1000.00 · Nearer=1000.00 · Higher=1001.00.
- [ ] Nearer عند التساوي (1000.50/0.50) → **1001.00** (tie-break للأعلى).
- [ ] يظهر سطر Round-off مستقل في فاتورة الخروج (طباعة).

## AC-7 — بطاقات الائتمان والرسائل

- [ ] Floor Limit يتحقق منه في تسويات FO/POS/BQT (QA-SYS-4: القرار — تجاوز الحد يفرض تفويضاً/رفضاً حسب سياسة، موثق).
- [ ] Print Bill Message يظهر في فواتير المنافذ المختارة خلال From→To فقط ويزول بعدها.

## AC-8 — المفاتيح السلوكية (Feature Toggles)

- [ ] `Hotel Feature Toggle` يخزن كل المفاتيح المرقمة المعروفة (قابل تراكمي: INI 56/58/64/74/283/404/504 + Attr 6/29/32 + Switches) مع module/risk/description.
- [ ] التفعيل يسجل audit (من/متى/قيمة قديمة→جديدة) — يفوق الأصل.
- [ ] تصدير/استيراد JSON كامل (بديل INI file — F-SYS-2).
- [ ] Mفاتيح عالية الخطورة تتطلب تأكيداً أو موافقة (حوكمة محسنة).

## خطة Smoke Test (تشغيل أولي 30 دقيقة)

1. **Bootstrap Wizard** (WF Bootstrap 1-8): إنشاء Property (Company) + عملة محلية + سعر + قسم + CC + Designation + UOM + Tax Code/Slab/Structure + Credit Card + مستخدم مشرف + مستخدم محدود.
2. منح صلاحية للمحدود على وحدة FO فقط → دخوله → التحقق: يرى FO ولا يرى POS؛ يحاول Add بلا حق → مرفوض.
3. حجب تقرير FO عنه (print/export) → التقرير يختفي خياراته.
4. اختبار الضرائب: بناء شرائح الدليل وإصدار فاتورة اختبار 750 → 26.25/18.75.
5. Round-off: فاتورة 1000.49 بالأنماط الأربعة.
6. تعطيل المستخدم → دخوله يُرفض → إعادة تنشيطه بكلمة مرور جديدة (برابط).
7. تفعيل Feature Toggle (مثلاً POS Attr 29) + audit يظهر السجل.
8. تقرير List Users Access يصدّق ما أعلاه.
