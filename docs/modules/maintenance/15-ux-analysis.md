# 15 — تحليل تجربة الاستخدام (UX Analysis) — وحدة MNT

> وحدة **Grid-First بامتياز**: النقر المزدوج يحمل أربع وظائف مختلفة، واللون أداة قرار لحظية، وF2/F3 تسريع روسنة، و"استعلام يُحرِّر" — أدوات كثيفة الكفاءة بمظهر 90s صارم.

---

## 1. اللون كلغة حالة (أولوية بصرية) ⭐

- "the record will be **highlighted in the color that was set for the priority level**" (OPR ص24) — عند إسناد الأولوية فوراً يتلوّن الصف.
- **القراءة البصرية:** مشرف يمسح عشرات المرشحين بالعين — الأحمر يقفز قبل أن يُقرأ أي نص. هذه **أول لوحة أولويات بصرية** موثقة في المشروع (سابق على أي Kanban).
- **الاستنتاج التصميمي:** نقل الفكرة إلى إعادة البناء = Color-Tag/Priority badge على قوائم العمل — مع كنبان حقيقي (راجع 16 F-MN-4).

## 2. النقر المزدوج — أربع وظائف (أثقل استثمار للإيماءة)

| الموضع | الوظيفة | المصدر |
|---|---|---|
| عمود Action Taken | **إدخال نص الإجراء** (تحرير خلية) | OPR ص9 |
| عمود Status | **تغيير الحالة** | OPR ص10 |
| عمود Select (NO→YES) | **انتقاء للتوليد** | OPR ص23-24 |
| عمود Priority | **إسناد أولوية** | OPR ص24 |
| خلية شبكة الورديات | فتح Shift Help | OPR ص16 |
| قائمة Complaint Status (Q) | **فتح السجل للتعديل** | RPL ص7 |

- إيماءة واحدة = "حرّر هذا الحقل/السجل" — عائلة تكرارات أوسع من POS (حيث كانت YES/NO للأكواب أساساً).
- **المخاطرة UX:** الاكتشافية (Discoverability) — وظيفة النقر المزدوج لا تُكتب على الشاشة؛ المستخدم الجديد يحتاج الدليل حرفياً.

## 3. Query-as-Console (الاستعلام الذي يُحرِّر) ⭐

- Complaint Status (Q): "view and print... **You can change the status**... **Enter the action taken**... **select the priority level**" (RPL ص7).
- **النمط:** تقرير بواجهة تعديل = أداة إشراف سريعة (تغلق شكوى من القائمة بلا فتح 3 شاشات).
- **الوجه المظلم:** يكسر توقع "التقارير للقراءة" — وقدوة TEL Error View (إعادة ترحيل من استعلام!) — في إعادة البناء: **Action من قائمة + تأكيد + صلاحية** (راجع 07).

## 4. تسريع إدخال الروستا (F2/F3)

- "You can press **F2 to Copy Paste previous CELL** and **F3 to Copy Paste previous ROW**" (OPR ص17).
- ملء شهر كامل لـ20 فنياً: قيم نمطية تُنسل بالوظائف — **أداة التسريع الأقوى الموثقة في وحدة غير POS**.
- المقابل الحديث: fill-down/drag-copy في شبكات الويب — لا فروق جوهرية، لكن F2/F3 أسرع على لوحة مفاتيح عربية بلا فأرة.

## 5. مصمم الطباعة (UDPF) — UX حرفي مطبعي ⭐

- **نموذج العقليية الطباعية:** صفوف محطية بمعدل "6 rows = 1 Inch" + Scales مساطر + Grid Lines + **Lock Controls** ("lock all the fields... to prevent the change in the alignment... you can still move the fields with **Ctrl + arrow keys**") — عقلية ما قبل WYSIWYG الكاملة.
- **الميزانية الحقيقية:** Print From/To (قص نص طويل حسب عرض المحطية) وLast Page (حقل لا يظهر إلا في الصفحة الأخيرة — UserId مثالاً) — حلول مطبعية خالصة لا نجدها في مصممي الويب.
- **Match Samples:** "take a sample printout... Printer = Print match samples" + عدد النسخ والأحرف — **معايرة تجريبية قبل الاعتماد** — دورة (صمم → عاير → اعتمد).
- **ملاحظة:** "Make Project Active" كخطوة إلزامية قبل التحرير — حماية ضد تحرير مشروع خاطئ (تأكيد صريح بمنطق السياق).

## 6. أنماط مساعدة الإدخال

| النمط | الشواهد | التقييم |
|---|---|---|
| F1 في كل مرجع | 12+ حقل F1 عبر الوحدة | خصوبة عالية قياسية |
| Job Order Help بمعايير مركبة | المصدر × تاريخ × قسم × غرفة/موقع (OPR ص7) | **أغنى Help بحثي عملياتي** |
| ثنائية Room/Location المتكيفة | F1 يعرض قائمة حسب الاختيار (OPR ص3) | ذكي ومقتصد |
| حساب آلي للقيمة | qty → value (OPR ص13) | تقليل أخطاء يدوية |
| توليد آلي للأرقام | complaint#/pm# | موحد |

## 7. القصور UX الموثق

| القصور | الأثر | المصدر |
|---|---|---|
| **لا إشعارات إطلاقاً** | شكوى حرجة تنتظر مشرفاً يفتح الشاشة | استنتاج من غياب أي قناة |
| الأولوية عند التسجيل غائبة | المُبلِّغ لا يعبّر عن الاستعجال! | OPR ص3 (النموذج) |
| **لا SLA/عدّاد متأخر** | Pending لا تميّز المتقادم (إلا بتقرير Resolution بعد الإغلاق) | RPL ص19 |
| رسالة Success بلا محتوى موثق | "The following message appears" (صورة غير مستخرجة) | RPL ص7 |
| طباعة Job Request لحظة واحدة | فرصة إعادة الطباعة مفقودة (Workflow ثقيل الورق) | OPR ص4 |
| الورديات ≤31 يوماً | لا تخطيط موسمي/سنوي | OPR ص16 |

## 8. توصيات النقل (للجلسات التصميمية — Phase 4)

1. **حافظ على اللون** — Priority color → badges + قوائم مفروزة بالأولوية (والنص يقرأ لمن يعانون عمى الألوان — إضافة نمط × الوسم اللوني).
2. **نقر مزدوج → إجراءات معلنة**: أيقونة/زر تحرير مرئي بجانب الخلايا (اكتشافية).
3. **Q-Console → قائمة إجراءات (Bulk actions) بصلاحية وتأكيد** وAudit trail (من غيّر الحالة).
4. **F2/F3 → fill-down** بالسحب + لوحة مفاتيح (احترام مستخدمي الكيبورد).
5. **بواباتا ENG#1/#2 → إعدادات Notification** حقيقية (طباعة اختيارية + قنوات رقمية).
6. **UDPF → Print Format Builder** (Frappe) مع نقل "Last Page/Print From-To" كسلوك طباعي متقدم عند الحاجة فقط.
