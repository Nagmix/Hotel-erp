## 5. فرص التحسين الموثقة (فوق الأصل)

1. Push notifications بديلاً/مكملاً لـ SMS (تكلفة+موثوقية).
2. لوحة SLA حية (Dashboard) بدل انتظار التقارير.
3. ربط Feedback بجودة الغرفة (Repeated Issues + Room history) لتوجيه الصيانة الوقائية (جسر نحو MNT).
4. أداء الفنيين → HR Appraisal (جسر اختياري مع HRMS — غير موجود في الأصل).
