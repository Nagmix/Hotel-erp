# 05 — قواعد العمل (Business Rules) — وحدة GTP

> **BR-GP-01..12** — قواعد قليلة لكن ثلاث منها بنيوية: **ثنائية Returnable** كمحور منظِّم لكل المخرجات · **الاستلام الجزئي** بوسم الكمية · **الاسترجاع ثلاثي المفاتيح**. لا معادلة رقمية واحدة في الوحدة (لا مبالغ أصلاً!).

---

## القواعد المؤكدة

| ID | القاعدة | المصدر |
|---|---|---|
| **BR-GP-01** | **التصريح وثيقة تصديق**: "A gate pass is a NOTE issued authenticating the details of goods taken out of the premises" — إثبات خروج لا حركة مخزنية | ص2 |
| **BR-GP-02** | **أسباب النثر المعيارية**: "for reasons like servicing, material transfers etc" — أمثلة مفتوحة لا قائمة مغلقة | ص2 |
| **BR-GP-03** | **Vendor ثنائي القناة**: الكود يُختار والاسم يُدخل يدوياً — قناتان منفصلتان لحقل واحد | ص2 |
| **BR-GP-04** | **ثنائية Returnable/Non-Returnable لكل صنف** (خيار داخل الشبكة) | ص3 |
| **BR-GP-05** | **Expected date of return حكر على المرتجع** (منطق الشبكة) | ص3 |
| **BR-GP-06** | **الملاحظات مشروطة بإدخال الكمية**: "When you enter the quantity you get the following screen" — نافذة تظهر ضمن سياق الكمية | ص2 Note |
| **BR-GP-07** | **الاستلام الجزئي متاح**: "Provision to tag partial items received are also provided" | ص3 |
| **BR-GP-08** | **استرجاث ثلاثي المفاتيح**: Gate Pass # / Vendor Name / Gate Pass Ref# | ص4 |
| **BR-GP-09** | **السجل للمرتجع فقط**: "all returnable Gate Passes issued by various departments" | ص7 |
| **BR-GP-10** | **المعلق بتاريخ As-on**: "print pending Gate Passes register as on a date" | ص8 |
| **BR-GP-11** | **الطباعة انتقائية بمحاور ثلاثة**: Date / Gate Pass # / Vendor + ثنائية Returnable + **اختيار طابعة** | ص10 |
| **BR-GP-12** | **تعديل الاستلام بالنقر المزدوج** على السجل المستهدف | ص5 Note |

## السلوكيات المشتقة [INFERENCE]

| الاستنتاج | الأساس |
|---|---|
| Pending = مرتجع لم يكتمل استلامه (كمية مستلمة < المصروفة) | بنية Query/Pending + Expected date |
| غير المرتجع لا يدخل دورة Pending أبداً | لا عودة متوقعة له |
| Vendor Name يخدم البحث (مفتاح استرجاع!) رغم إدخاله اليدوي | BR-GP-08 — الاسم الحر يصبح مفتاح بحث |
| كل تصريح يخص مركز تكلفة واحداً | dropdown واحد (لا شبكة مراكز) |

## القواعد الغائبة (تحليل الفجوة)

| الغياب | الأثر |
|---|---|
| لا حد أقصى للاستلام (الكمية المستلمة > المصروفة؟) | ثغرة كمية غير محصنة (V-GP) |
| لا قاعدة إغلاق تصريح مستوفى | متى يخرج من Pending؟ |
| لا معالجة عدم العودة | مرتجع خالد Pending |
| لا ربط حركة مخزن (MGT) رغم "material transfers" | خروج مادي بلا أثر مخزني رقمي |
| لا قاعدة توقيت (تصريح بتاريخ مستقبلي؟) | غير مقيد |
