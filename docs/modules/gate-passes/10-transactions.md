# 10 — المعاملات (Transactions) — وحدة GTP

> **T-GP-01..02** — معاملتان فقط (الإصدار والاستلام) لكن الاستلام **أغنى معاملة استلام في المشروع نسبياً**: ثلاثي مفاتيح الاسترجاع + وسم جزئي + تعديل بالنقر المزدوج. لا معاملة ثالثة (لا شطب/لا إغلاق/لا إلغاء) — والدورة تدور أو تتجمد.

---

## T-GP-01: إصدار تصريح (Issue Gate Pass)

| البعد | الموثق |
|---|---|
| المفتاح | Gate Pass # [توليد غير موثق — UNK-075] + **Ref# حر** |
| الرأس | Date + Cost Center (dropdown) + Authorized By (حر) + Vendor Code (اختيار) + **Vendor Name (يدوي)** + Responsibility (حر) |
| الأصناف | شبكة: Particulars + UOM + Returnable + Quantity + Expected date of return |
| الملاحظات | نافذة منبثقة أثناء إدخال الكمية |
| الحالة الناتجة | نشط؛ مرتجع → ينتظر استلام (Pending قابل للظهور) |
| العكس | ❌ لا تعديل/إلغاء موثق |

## T-GP-02: استلام (Receive Gate Pass) — ⭐

| البعد | الموثق |
|---|---|
| الاسترجاع | (Gate Pass # | Vendor Name | Ref#) + Help + OK |
| الوسم | Date + Quantity لكل صنف |
| **الجزئية** | "Provision to tag **partial items** received" — وسم الكمية المستلمة فقط (كمياً) |
| التعديل | "Click [استلام] again and **double-click on the record** that you want to modify" — سجل استلام قابل للتصحيح |
| التراكمية | [INFERENCE] دفعات استلام متعددة لكل تصريح (كل وسم سجل Date+Qty) |
| الحالة الناتجة | تراكم المستلم؛ اكتمال = خروج من Pending (قاعدة الإغلاق غير موثقة!) |
| العكس | التعديل بالنقر المزدوج فقط — بلا أثر تعديل موثق |

## مصفوفة دورة الحياة

```
تصريح مرتجع:   Issued ──→ (Pending) ──→ Partial receipts ──→ Complete [؟ متى]
                  │                                       
                  └─ تجاوز Expected date ──→ يظل Pending (لا معالجة متأخر!)
تصريح غير مرتجع: Issued ──→ (نهائي — لا دورة عودة)
```

## مقارنة عائلية (معاملات الاستلام في المشروع)

| الوحدة | الاستلام | الجزئية | المفتاح |
|---|---|---|---|
| MGT (Goods Receipt) | كاملة بالمخزن | ✓ | PO |
| **GTP** | وسم ورقي | ✓ موثق حرفياً | **ثلاثي** (GP#/Vendor/Ref#) |
| FNB (Kitchen Stock) | جرد فعلي | — | — |

> الوحدة الأضأل تملك وصف الاستلام الجزئي الأصرح نصاً — التوثيق النوعي لا يتبع الحجم.
