## 5. قرارات إعادة البناء (D-GP-8 — UX)

1. أسماء أزرار صريحة موثقة (سد [NOT DOCUMENTED]).
2. Vendor Name آلي من الكود مع override بصلاحية.
3. Popup الملاحظات: يبقى (تراث مميز) لكن بلا إلزامية شرط الكمية — حقل Remarks عادي في البند + سلوك النافذة كاختصار.
4. إضافة شارة حالة مرئية (Pending/Complete/Overdue) لكل تصريح — يغلق فجوة الشفافية.
5. Print Format مزدوج: بطاقة بوابة صغيرة (للحرس) + A4 سجل.
