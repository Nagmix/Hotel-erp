# 02 — التهيئة والإعدادات (Configuration) — وحدة GTP

> **صفر تهيئة.** لا بارامترات · لا بوابة تفعيل · لا نِسب INI · لا Module Attributes · لا System Attributes · لا تواريخ قطع — أول وحدة في المشروع **لا تملك أي شاشة إعداد إطلاقاً** (حتى MNT "الجزيرة" كان لها ماسترات كإعداد). تُشرَّع فور تركيبها.

---

## 1. الدليل على الصفرية

| الفحص | النتيجة |
|---|---|
| شاشة بارامتر/Setup في TOC (7 بنود) | ❌ لا شيء — كلها عمليات واستعلامات |
| INI switch | ❌ (ثامن أعضاء عائلة "بلا INI": CARE/MEM/SLM/TEL/MNT + عادت في FNB/FXD) |
| Module/System Attributes | ❌ |
| Start Date / Cut-off | ❌ (لا علاقة ببوابات FNB/FXD/HRP) |
| تعريف Returnable types | ❌ (ثنائية بسيطة نعم/لا فحسب) |

## 2. التهيئة الضمنية المستعارة

| العنصر | يُدار في | الأثر على GTP |

| Cost Centers | FAS/عائلة مراكز التكلفة | dropdown الإصدار — الربط التنظيمي الوحيد |

## 3. ما يعنيه الغياب الكامل (قراءة معمارية)

- **الوحدة عديمة الحالة** (Stateless configuration): لا شيء يضبط سلوكها — كل "الإعدادات" بيانات وقت الإدخال.
- **التوثيق النثري بدل الهيكلي**: أسباب الإصدار ("servicing, material transfers etc") وطرق الاسترجاع موثقة نصاً لا شاشات — دليل "مستخدم نهائي" صرف (النمط الأضأل من Touch Screen حتى).
- **قرار إعادة البناء D-GP-1:** يُبنى DocType إعداد واحد صغير (Gate Pass Settings): Reason Master لخروجات معيارية + إلزامية قوائم (Vendor/UOM/Cost Center) + سياسة Pending (بعد كم يوم يعد التصريح متأخراً؟) — كلها قرارات [NOT DOCUMENTED] تُحسم تصميمياً.
