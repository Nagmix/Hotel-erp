# 06 — قيود الإدخال والتحقق (Validations) — وحدة GTP

> **V-GP-01..07** — أدنى كثافة تحقق في المشروع: لا حدود أطوال · لا تحقق تناظر · لا آلي واحد؛ الوحدة تثق بالمستخدم ثقة عمياء (أسماء حرة، صنف نصي حر، كمية بلا سقف استلام).

---

## القيود الموثقة (كلها ضمنية من بنية الشاشات)

| ID | القيد | الأساس |
|---|---|---|
| **V-GP-01** | Cost Center من dropdown — لا حر | "From the Cost Center **dropdown list** select" (ص2) |
| **V-GP-02** | Vendor **Code** اختيار (قائمة) | "select the vendor code" (ص2) |
| **V-GP-03** | Vendor **Name** إدخال يدوي | "enter the vendor's name" (ص2) |
| **V-GP-04** | Returnable اختيار ثنائي داخل الشبكة | "select if the goods are returnable or not" (ص3) |
| **V-GP-05** | استرجاع الاستلام بمفاتيح ثلاثة (اختيار عضوي) | ص4 |
| **V-GP-06** | استلام (Date + Quantity) إدخال مطابق لبنية الشاشة | ص4-5 |
| **V-GP-07** | الطباعة تستلزم محوراً (Date/GP#/Vendor) + نوع المرتجع + طابعة | ص10-11 |

## ثغرات التحقق الموثقة الغياب

| الثغرة | السيناريو | الخطورة |
|---|---|---|
| **لا سقف كمية الاستلام** | استلام 10 من مصروفة 5 | عالية — سالبية منطقية |
| لا تحقق تاريخ الاستلام ≥ تاريخ الإصدار | استلام قبل الإصدار | متوسطة |
| لا حدود نصوص (Particulars/Names/Remarks) | إدخالات فارغة/ضخمة | منخفضة |
| لا إلزام Expected date للمرتجع | مرتجع بلا موعد → لا Pending صحيح | متوسطة |
| لا إلزام Quantity > 0 | صنف بلا كمية | منخفضة |
| لا تحقق Ref# فريد | تكرار مرجع حر يربك الاسترجاث | منخفضة |
| لا تحقق Vendor Name يطابق الكود | كود مورد A واسم مورد B! | متوسطة (BR-GP-03 يسمح بنيوياً!) |

> **قرار إعادة البناء D-GP-2:** يُضاف: سقف الاستلام cumulative ≤ الكمية المصروفة · استلام ≥ تاريخ الإصدار · إلزام Expected date عند Returnable=نعم · **توليد Vendor Name آلي من الكود** (مع سماح تعديل استثنائي موثق) — إغلاق الثغرات السبع.
