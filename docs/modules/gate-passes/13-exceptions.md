# 13 — الاستثناءات والسلوكيات الحدية (Exceptions & Edge Cases) — وحدة GTP

> **لا استثناء لوني ولا رسالة خطأ واحدة** — أهدأ وحدة سلوكياً في المشروع على الإطلاق. الغرابة الوحيدة الموثقة: **اسم وظيفة يذكر الأصل** ("Double-click **Asset Issue Gate Pass** under Gate Pass" — متخلف من عنوان قديم؟) و**البوباب الشرطي بالكمية**؛ وكل "الحدية" هنا فجوات دورة (عدم عودة/تجاوز موعد/إعادة طباعة).

---

## 1. الاستثناءات الموثقة

| # | الاستثناء | النص | القراءة |
|---|---|---|---|
| **E-GP-01** | **"Asset Issue Gate Pass"** | "Double-click **Asset Issue** Gate Pass under Gate Pass to view the following screen" (§1 ص2) — TOC اسمها "1_Issue_Gate_Pass" لكن المتن يستدعي **Asset Issue**! | بقايا تسمية (تصريح أصل؟) أم خطأ تحريري — [UNCERTAIN] يدعم فرضية I-GP-05 (مزج أصل/مادة في التصميم الأصلي) |
| **E-GP-02** | **نافذة شرطية بحقل** | "When you **enter the quantity** you get the following screen, where you can enter any remarks" (Note ص2) | أول popup مشروط بقيمة حقل في المشروع (Trigger-on-entry) |
| **E-GP-03** | **Vendor بلا اسم آلي** | Code select + Name enter (ص2) | انفصال مرجعي مقصود أم نقص تصميم؟ (BR-GP-03) |

## 2. الحالات الحدية (فجوات الدورة)

| الحالة | السؤال | الأثر |
|---|---|---|
| **مرتجع لا يعود أبداً** | لا شطب/إغلاق/تحويل دائم | Pending خالد — السجل ينمو بلا نهاية |
| تجاوز Expected date بلا استلام | يدخل Pending تلقائياً؟ أم يعتمد as-on فقط؟ | [INFERENCE] As-on هو الآلية — لا Job/تنبيه |
| استلام كامل ثم زيادة | الكمية التراكمية > المصروفة؟ | ثغرة V-GP (لا سقف) |
| استلام غير مرتجع | مسموح؟ مستحيل بنيوياً؟ | [NOT DOCUMENTED] |
| **إعادة طباعة تصريح** | نسخة ثانية بلا إبطال الأولى (على خلاف TSC Check: "cancels old check number and generates a new") | خطر أمني ورقي: نسختان لنفس الخروج |
| تعديل استلام | بالdouble-click — بلا سجل تعديل | أثر تدقيقي مفقود |
| Ref# مكرر | الاسترجاث بRef# يضرب عدة تصاريح؟ | [NOT DOCUMENTED] |

## 3. سيناريو تركيبي (دورة كاملة بأرقام)

```
إصدار: تصريح GP#1001 (مركز F&B) — بند واحد "مضخة صودا" Qty 2, UOM قطعة,
       Returnable=نعم, Expected 15-01-2026, Vendor: V-230/اسم يدوي
اليوم 15: لم يعد → Pending Gate Passes (as-on 15-01) يظهر GP#1001
اليوم 18: عادت 1 → Receive (بGP#) → وسم Date 18-01 + Qty 1 (جزئي)
اليوم 25: عادت 1 → وسم ثانٍ → التراكمي 2 = المصروفة
         [اكتمل؟ لا قاعدة إغلاق موثقة — يظل ظاهراً بPending حتى متى؟]
لو لم تعد الثانية: خالد Pending بلا معالجة — القرار D-GP-7 (تحويل دائم)
```
