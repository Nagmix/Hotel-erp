# 18 — معايير القبول (Acceptance Criteria) — وحدة GTP

> **8 مجموعات / 32 معياراً + Smoke Test من 16 خطوة** — التركيز على: ثنائية Returnable كمحور · الاستلام الجزئي التراكمي بسقف · الاسترجاث ثلاثي المفاتيح · المعلق as-on · السجل للمرتجع فقط · إدارة إعادة الطباعة (الأمنية) · إغلاق عدم العودة.

---

## المجموعات

### AC-01: الإصدار (6)
1. حفظ التصريح يتطلب: Ref# + Date + Cost Center + Authorized By + Vendor + Responsibility + بنداً واحداً على الأقل.
2. كل بند يحمل Particulars + UOM + Quantity + **خيار Returnable صريح**.
3. Expected date of return **إلزامي عند Returnable=نعم** (V-GP المكمّل).
4. نافذة الملاحظات تُتاح عند إدخال الكمية وتُخزن على مستوى البند.
5. Gate Pass # يُولَّد آلياً (naming_series) ولا يُعدَّل.
6. لا تعديل/إلغاء بعد الإصدار إلا بصلاحية + سجل (Workflow).

### AC-02: العلاقة بالمورد (3)
7. Vendor Code من قائمة موحدة (Vendor Master) و**Vendor Name يُجلب آلياً**.
8. الاسم يبقى قابلاً للتعديل الاستثنائي الموثق (override بصلاحية).
9. الاسترجاث بـVendor Name يطابق الاسم المخزن (لا تطابق خارجي).

### AC-03: الاستلام (6)
10. الاسترجاث يعمل بالمفاتيح الثلاثة (GP# / Vendor Name / Ref#) عبر Help.
11. كل دفعة استلام = (Date + Quantity) على بند محدد.
12. **الاستلام الجزئي**: Σqty_received ≤ quantity المصروفة (رفض التجاوز — سقف تراكمي).
13. Date الاستلام ≥ تاريخ الإصدار.
14. تعديل الدفعة بالنقر المزدوج يعمل **مع Version Log** (أثر التعديل).
15. استلام بند غير مرتجع **يُمنع** (قرار مكمل).

### AC-04: الحالة والمعلق (4)
16. الحالة محسوبة لحظياً: Non-Returnable → نهائي · (Σ<qty) → Pending · (Σ=qty) → Complete.
17. **Overdue**: مرتجع تجاوز expected_return_date بلا اكتمال يُوسم (scheduler يومي).
18. Pending Gate Passes (as-on date) يعرض بالضبط المعلق بتاريخ التقييم.
19. تصريح Complete يخرج من كل قوائم Pending.

### AC-05: السجلات والتقارير (5)
20. **Gate Pass Register يعرض المرتجع فقط** (غير المرتجع غائب بنيوياً).
21. checkbox 'Include remarks' يظهر ملاحظات البنود في الورق.
22. Query/Report بمحاور موحدة: مراكز + (Date Range/As-on/GP# Range) + (R/NR/All) + (Pending/All) + **Vendor + Ref# (مكمّلان)**.
23. كل المخرجات تتقيد بمرشحات الحالة والنوع (لا تسرب).
24. الطباعة بثلاثة محاور (Date/GP#/Vendor) + نوع + **طابعة مختارة**.

### AC-06: إدارة الطباعة (الأمنية) (3)
25. كل طباعة تصريح تسجل **"Printed" بطابع زمن** (نسخ = عدد مرات).
26. إعادة الطباعة فوق العتبة تتطلب صلاحية Auditor.
27. بطاقة البواقة تحمل: GP# + Date + Cost Center + Authorizer + Responsibility + الأصناف + المرتجعية + الموعد المتوقع.

### AC-07: الإغلاق (عدم العودة) (2)
28. زر **"Close as Not Returned"** يحول المرتجع المتجمد إلى خارج نهائي + خروج من Pending + سجل قرار.
29. لا حذف فيزيائي للتصاريح أبداً (أرشيف دائم — أداة ضبط).

### AC-08: العزل المحاسبي (3)
30. لا حقل مالي واحد في أي شاشة (Amount/Currency/Account غائبون).
31. لا قيد GL يولَّد من أي معاملة (فحص سالب).
32. الربط المخزني (إن فُعّل اختيارياً) يولّد Material Transfer — لا Journal.
