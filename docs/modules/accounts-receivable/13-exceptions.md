# 13 — الحالات الحدية والاستثناءات (Edge Cases) — وحدة ACR

> 30 حالة حدية (E-AR-01..30) مرتبة بحسب عائلة الخطر. كل حالة بمصدرها وبالحسم إن وُجد.

---

## أ. حالات الصرف والفوارق

| ID | الحالة | السلوك الموثق | المصدر |
|---|---|---|---|
| E-AR-01 | سداد بعملة أجنبية بعد تغير السعر | **سعر تاريخ الفاتورة** معتمد — ربح/خسارة الصرف الدفترية ممنوعة تصميمياً | ACR-OPR §1 ص6 |
| E-AR-02 | التعديل بعملة أجنبية | استثناء: **سعر تاريخ التعديل** (لا سعر الفاتورة) | ACR-OPR §1 ص8 |
| E-AR-03 | سداد > إجمالي المعلق | حوار Yes/No لتوليد **إيصال بالفارق** | ACR-OPR §1 ص7 |
| E-AR-04 | إيصال يفوق الفواتير المحددة | الفارق يبقى **unallocated** للجلسة التالية | ACR-OPR §2 ص11 |

## ب. حالات القفل والإلغاء (الأخطر)

| ID | الحالة | السلوك | المصدر |
|---|---|---|---|
| E-AR-05 | تعديل قيد **مفوتر** | ممنوع — إلا Company Name/Branch (INI #74=0)؛ البديل: **Cancel Invoice** → تعديل → إعادة فوترة | ACR-OPR §1 ص10 |
| E-AR-06 | خطأ كتابي (رقم/تاريخ فاتورة) **بعد SOA** | **Outstanding Update** يعدل: Bill#/Date · Description · Bank/CC Details فقط — دون فتح الشهر | ACR-OPR §5 ص14-16 |
| E-AR-07 | تعديل قيد **بعد SOA** وليس كتابياً | Rollback SOA من شهر القطع **حتى آخر معالج** → تعديل → إعادة معالجة كل الشهور المفتوحة | ACR-OPR §8 ص21 |
| E-AR-08 | قيد معدل **ومفوتر ومطابَق** | **ثلاث طبقات** بالترتيب: Cancel Invoice → حذف الإيصال الدائن → (Rollback إن لزم) → تعديل → إعادة بناء السلسلة (فوترة + تسجيل + مطابقة) | ACR-OPR §8 ص21 |
| E-AR-09 | Rollback لشهور متعددة | مدى لا نقطة: "from the entered Month/Year **till the last processed**" — كل الشهور اللاحقة تُفتح دفعة واحدة | ACR-OPR §8 ص21 |
| E-AR-10 | تعديل الافتتاحيات بعد SOA لشهر البداية | نفس نمط Rollback → تعديل → إعادة المعالجة | ACR-SET §2 ص3 |
| E-AR-11 | فاتورة مطلوب طباعتها ثانية | ممنوع — **Reprint** حصراً بنطاق أرقام الفواتير | ACR-BIL §2 ص6 |
| E-AR-12 | سلسلة SOA "قفزة شهر" | ممنوع — الشهر آلي متسلسل والحقل غير قابل للتحرير | ACR-OPR §7 ص21 |
| E-AR-13 | AR Start Date خاطئ | **لا علاج موثق** — "not allowed to update" — الحل الوحيد بيانات جديد/دعم فني | ACR-SET §1 ص1 |
