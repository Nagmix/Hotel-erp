# 15 — تحليل تجربة المستخدم (UX Analysis) — وحدة ACR

> ملاحظات نمط التفاعل الموثقة في الأدلة الخمسة — مدخلات مباشرة لتصميم الواجهة الجديدة (Next.js + RTL عربي أولاً).

---

## 1. أنماط التفاعل الموثقة

| النمط | التفصيل | المصدر |
|---|---|---|
| **أزرار النمط العام (Identifying Standards)** | Add · Modify · Delete (شرطي) · Browse · Prev (بعد Browse) · Next (بعد Browse) · Save · Tools (Command Window/Internode/Calculator/Calendar/Scratch Pad/Yellow Pages) · Exit | ACR-SET ص1-2 |
| **F1 = Help النظامي** | كل الحقول المرجعية (Company/Banks/Card Types/Bills/Receipts...) | كل الملفات |
| **Double-click = تحديد/تنقيب** | اختيار صف (Option→Yes) + التنقيب العميق في Follow-Up | ACR-OPR §2 + CRT |
| **Enter = تفعيل** | صفوف AR User Access (تبديل Yes/No) + اختيار مستخدم | ACR-SET §4 ص10 |
| **عرض عمودي للجداول المالية** | Multiple Bill Settlement: أعمدة 11 معلومة في صف واحد | ACR-OPR §1 ص5 |
| **تبويبات الشاشات الكبيرة** | Debtors Follow-Up: 4 تبويبات | ACR-CRT |
| **أزرار وظيفية بأيقونات** (بلا نص موثق) | Debit/Credit/Adjustment/POST/Adjust/Bank/Print... | كل شاشات OPR |

## 2. نمط التنقيب العميق (Drill-Down) — أفضل ممارسة موثقة

سلسلة المتابعة (CRT):
`قائمة الشركات → قيود → (double-click) فاتورة بمدين/دائن → (double-click) بند → (double-click) ضيف/تقسيم المبلغ`

**قرار UX للنظام الجديد:** هذا النمط (التنقيب من الرصيد حتى الشحنة) هو **جوهر شاشة "ملف الذمة"** المقترحة — Breadcrumb تفاعلي: شركة ← فاتورة ← بند ← ضيف.

## 3. ملاحظات RTL/العربية المستنبطة

| العنصر | القرار المقترح | الأساس |
|---|---|---|
| جداول المطابقة (مدين/دائن) | الأعمدة المالية بعرض ثابت + أرقام لاتينية (محاسبياً) + تسميات عربية | أعراف محاسبية |
| **إشارات Adjustment** (+/−) | تُعرض كشارات ملونة (أخضر/أحمر) بدل الرمز المجرد — الوثيقة تصف −50 بالبداية | ACR-OPR §1 ص8 |
| عمود UnTag (No→YES) | تبديل نقري واضح (Switch) بدل double-click خفي | ACR-OPR §6 ص19 |
| حوار Yes/No المتكرر | نوافذ حوارية عربية موحدة (توليد إيصال الفارق مثال) | ACR-OPR §1 ص7 |
| حالات الفواتير | شارات (Billed/Unbilled/Cancelled) — التقارير تفلتر بها | ACR-RPL §2 ص4 |

## 4. نقاط الألم الموثقة (Pain Points → فرص تحسين)

| الألم | الدليل | فرصة النظام الجديد |
|---|---|---|
| **منطق INI معكوس** (#56: 0=تفعيل!) | ACR-OPR §1 ص10 | مفاتيح دلالية إيجابية بواجهة إدارة |
| **الأزرار أيقونية بلا نص** | كل شاشات OPR | أزرار نصية عربية واضحة (قيد مدين/قبض/تسوية) |

| **الحذف لإعادة المطابقة** (تعديل قيد مطابَق) | ACR-OPR §8 ص21 | إعادة تخصيص مباشرة (reallocate) مع Audit |
| **تعدد النوافذ للعمليـة الواحدة** (Credit→POST→Bank→Save) | ACR-OPR §1 ص4-7 | معالج واحد خطوات متتالية |
| **شرط Pgm ID الصامت** (لا طباعة بلا تعريفه) | ACR-BIL §1 ص2 | تحقق مسبق برسالة عربية صريحة |
| **تسجيل Opening Balance ثم قفله بم SOA** | ACR-SET §2 ص3 | معالج تأسيس بمراحل مع فحوصات |
