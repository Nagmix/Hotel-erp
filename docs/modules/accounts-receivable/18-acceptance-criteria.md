## خطة اختبار الدخان (Smoke Test) لوحدة AR

1. تفعيل AR بشهر محدد → محاولة تغييره (يفشل).
2. إنشاء شركة (كود TTT+XXXX) + حد ائتمان 1000.
3. قيد مدين 1200 يدوي → **يُمنع** (تجاوز الحد).
4. رفع الحد → القيد ينجح + ترحيل GL آلي.
5. قبض 500 بشيك (unallocated) → Match على الفاتورة بـ 500.
6. طباعة فاتورة → محاولة تعديل القيد (يفشل) → Cancel → تعديل → إعادة فوترة.
7. معالجة SOA للشهر → محاولة تعديل (يفشل) → Rollback → تعديل → إعادة.
8. متابعة على الفاتورة + موعد + Projection → تقرير التوقعات.
9. تقرير Aging Summary بفترات مخصصة + CC Register لمدى الشهر.
10. تقرير Transaction Audit يعرض Old/New وDel.
