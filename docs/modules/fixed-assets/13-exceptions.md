# 13 — الاستثناءات والسلوكيات الحدية (Exceptions & Edge Cases) — وحدة FXD

> **ثلاث استثناءات لونية/سلوكية فريدة + عائلة "اللم يأتِ بعد" + حالات حدية محاسبية غير محسومة** — الوحدة الأهدأ سلوكياً بين المحاسبية (لا رسائل خطأ حرفية واحدة موثقة!) لكن أثقلها عواقب عند السلوك غير المحدد.

---

## 1. الاستثناءات الموثقة

| # | الاستثناء | النص الحرفي | الدلالة |
|---|---|---|---|
| E-FX-01 | **الأزرق = غير مربوط** | "If any of the subgroups is not linked, then those assets posting will not be done and the same will be **highlighted with blue color**" (ص16) | اللون الرابع (MNT أولويات/POS/FNB pink-green) وهنا **لغة إقصاء ترحيلي** — الأصل يُحسب لكن لا يصل الدفاتر |
| E-FX-02 | **تساوي البيع مع القيمة يطفئ P&L** | "If asset value and sales value is equal, then **profit and loss ledger selection will be deactivated**" (ص13) | أول حقل **يُعطَّل ديناميكياً بقاعدة محاسبية** — ليست إخفاء بل تعطيل تفاعلي |
| E-FX-03 | **WDV محسوب غير مرحَّل** | الحساب "in 2 methods" (ص14) مقابل "posting... **straight line only**" (ص16) | انفصال منهجي بنيوي: دفاتر SLM دائماً وتحليلات بنِسب WDV — تقارير ≠ دفاتر بحكم التصميم |

## 3. الحالات الحدية (بلا مواصفة — خريطة الخطر)

| الحالة | السؤال المفتوح | الأثر |
|---|---|---|
| **Rollback بعد ترحيل** | يُسترجع الحساب — فماذا عن القيود المرسلة لـFAS؟ | دفاتر تحسب إهلاكاً لم يعد موجوداً — **أخطر سيناريو في الوحدة** (UNK-071) |
| تغيير INI #475 منتصف العمر | هل يُعاد حساب التاريخ؟ WDV يبدأ من WDV الحالي؟ | تبديل منهج بلا قاعدة انتقال |
| أصل بكمية 0 بعد بيع كامل | يظل بالسجل (Zero Quantity checkbox)؟ يُحذف؟ | نهاية الحياة غير محددة |
| Disposal بلا مبلغ | هل يرحَّل Loss بقيمة دفترية كاملة؟ | نص القيود للبيع فقط |
| Component يضاف بعد شهور إهلاك | يعاد الحساب من تاريخ المكوّن؟ يُمدد العمر؟ (UNK-070) | قاعدة إهلاكية مفقودة |
| بيع أصل غير مربوط | "If selected asset is linked with ledger, then FA posting screen **will populate**" — غير المربوط؟ | سجل بلا قيد (متسق مع E-FX-01) |
| نسب Method لسنة مالية جديدة | تنتقل تلقائياً؟ تُعاد؟ | FY transition غير موثقة (UNK-070) |
| العملة الأجنبية للأصل | قيمة تاريخ الشراء أم بتاريخ اليوم؟ Rate آلي "as per currency factor" | لحظة التقييم غير محددة |
| Last Dep. Post > Last Dep. Calc | ترحيل قبل حساب؟ | لا حاجز موثق بين الذاكيرتين |
| حذف/تعديل معاملة بيع | لا Cancel موثق | **لا عودة في وحدة ترحيلية** |

## 4. رسائل النظام الموثقة

> **صفر رسائل حرفية** — أهدأ وحدة محاسبية إطلاقاً (مقابل HRP/FNB/Care الغنية بالرسائل). كل "الردود" بنيوية: قفل الحقل · تعطيل الاختيار · الإبراز الأزرق.

## 5. سيناريو تركيبي للأثر (Smoke نهاية العمر)

```
أصل: قيمة 10,000 · residual 2,000 · 10 فترات SLM (800/فترة)
بعد الفترة 10: NBV = 2,000 (=residual)
البيع بـ2,500 → Sale > Asset value(الدفترية) → P&L Gain 500 يُرحَّل
[لو بيع بـ2,000 بالضبط → P&L يتعطل (E-FX-02) — قيد بسطرين فقط!]
[لو بيع بـ1,500 → Loss 500]
النص الفلسفي الموازي: "company will assume the value... to be nil by the end... any amount recovered... **nominal profit**" — سيناريو الدليل الأصلي بافتراض residual=0
```
