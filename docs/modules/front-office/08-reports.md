# 08 — التقارير (Reports) — وحدة Front Office

> التقارير المرصودة في وثائق FO المقروءة (REG/CAS/...). **✅ الكتالوج الكامل اكتمل في Phase 7 (الجلسة 16):** FOM-REP (120 ص — ~135 تقريراً + 28 فرعياً) + FOM-SMS (14 ص) → **[`docs/reports/front-office/`](../../reports/front-office/)** (12 ملفاً: 00-overview + المحرك + 7 عائلات + مصفوفة التواريخ + SMS + التحويل).

---

## تقارير/مخرجات موثقة في الوثائق التشغيلية

| التقرير/المخرج | الوظيفة | المصدر |
|---|---|---|
| **Denial Report** | حجوزات مرفوضة (Turn Away) | FOM-REG §11 (ص81-82) |
| **Invoice Control Report** | تفصيل تعاريف الغرف لفواتير الوكلاء | FOM-REG §9 (ص78-80) |
| **Yearly Chart (مطبوع)** | إحصاءات السنة يومياً + Include Over Booking | FOM-REG §1 (ص12-13) |
| **Detailed Position (مطبوع)** | موقف الغرف التفصيلي (OOS/OOO/Mتاح + Stay Over/Arrivals/Departures) | FOM-REG §1 (ص11-12) |
| **Receipt (طباعة لكل تسوية)** | Room/Reg/Bill/Receipt#/Date/Net | FOM-CAS §13 (ص78) |
| **Bill Summary / Bill (طباعة)** | فاتورة الضيف (شخصية التنسيق لكل ضيف) | FOM-CAS §Check Out (ص37) |
| **Prov Bill** | فاتورة عرضية (بلا رقم، غير قابلة للتسوية) | FOM-CAS ص37 |
| **Reprint POS Bill** | إعادة طباعة فواصل المنافذ (Normal/Compliment) | FOM-CAS ص42-43 |
| **Spool** | نظام طباعة مؤجل (Spool window) | FOM-REG §9 (ص74-75) |
| **Graphs: 2D Bar / 2D Line** | تمثيل بياني لموقف الغرف + Zoom | FOM-REG §1 (ص9-10) |

> ✅ **تم الفهرس الكامل** (الجلسة 16): قائمة FOM-REP الرسمية كاملة (~135 تقريراً/28 فرعياً) مع الغرض والمرشحات والقواعد → [`docs/reports/front-office/`](../../reports/front-office/) (الصلاحيات: غير موثقة في الدليل — GAP-FOR-D01).
