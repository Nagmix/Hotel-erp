# 15 — تحليل تجربة المستخدم (UX Analysis) — وحدة FAS

> أنماط التفاعل الموثقة في FAS — تغذي تصميم الواجهة الجديدة (Arabic-First RTL).

---

## 1. أنماط التفاعل الموثقة

| النمط | الموثق | الدلالة التصميمية |
|---|---|---|
| **شاشة أم جامعة (FA Transactions)** | 15 خياراً فرعياً في شاشة واحدة بأشرطة جانبية (tabs: Period/Master/Link) | في الواجهة الجديدة: WorkSpace محاسبي موحد بتبويبات، لا قوائم متناثرة |
| **Drill-down حتى التعديل** | تقرير → سجل → معاملة → **تعديل** (Day Book، Transaction Search) | نمط "البصر ثم التصحيح في مكان واحد" — لكن مقيد بصلاحيات وقفل الفترة |

## 2. نقاط ألم موثقة (تُعالج في التصميم الجديد)

1. **إلزامية الترتيب المعقد:** قبل أي ترحيل 4 متطلبات إعداد (Sales type + FY + رابطان) — يجب أن يكتشفها النظام الجديد ويعرض checklist إعداد.
2. **الفرق غير الموزع يظهر متأخراً** (عند الترحيل): يُفضل تحقق مسبق عند تعريف كود إيراد جديد غير مربوط.
3. **قفل Audited بلا تنبيه مسبق**: يجب إظهار حالة الشهر/السنة في شريط الحالة.
4. **Document Number لكل نوع ولكل سنة يدوياً** — قابل للأتمتة الكاملة.
5. **الطباعة بمنافذ فيزيائية (LPT/COM/USB)** — نمط قديم يُستبدل بطباعة ويب/خدمة.
