# 15 — تحليل تجربة المستخدم (UX Analysis) — وحدة POS

> Touch Screen Manual هو **أوثق مصدر UX تفاعلي في الحزمة كلها** (شاشة بلوحة مفاتيح على الشاشة + أيقونات + "؟" للمساعدة). هذه الوحدة هي **الحجر الزاوي لتصميم الواجهة الجديدة** لأنها الأكثر استخداماً يومياً.

---

## 1. أنماط التفاعل الموثقة (TS)

| النمط | التفصيل | المصدر |
|---|---|---|
| **لوحة مفاتيح على الشاشة** | "Click here to activate Online Keyboard" — لـ UserID/Password | TS ص2 |
| **لوحة أرقام Number Pad** | للكميات/Covers/الأسعار/التقسيمات — في كل مكان | TS ص10/14/25/29 |
| **اختيار متدرج بالمستويات** | قائمة 4 مستويات (L1 أول 3 صفوف → L2 → L3 → **الأصناف L4**) | TS ص13 |
| **+/− للكميات** | زرّا زيادة/نقصان بجانب QTY/Covers | TS ص10/14 |
| **أيقونات الحالة** | **Waiter = مشغولة · Printer = مطبوعة غير مسوّاة** | TS ص16/41 |
| **زر "؟" Help** | اختيار Check #/Table # | TS ص32/40 |
| **Others menu** | تجميع الوظائف النادرة (Change Restaurant/NC/Table Transfer/Link/Suffix) | TS ص6/11/37/43 |
| **أزرار رئيسية مباشرة** | T.Trnf/S.Trnf/NC/Order/Check/Settle على الشاشة الرئيسية | TS |
| **الرسائل الاستفتائية** | Resettlement YES/NO | TS ص36 |
| **قائمة أسباب Reasons** | معرَّفة + **إنشاء فوري** بزر الثلاث نقاط | TS ص17 |
| **السحب المباشر** | حقل Swipe Card يستقبل التركيز آلياً | TS ص34 |

## 2. نمط "الشاشة الرئيسية الحية" (Main Screen Status)

شريط الحالة الدائم: **المنفذ والجلسة · الكاشير المسجل · تاريخ الفاتورة الحالي · الطاولة المفتوحة · النادل الحاضر** (TS ص9) — **قرار UX مباشر:** شريط علوي ثابت بالسياق (Context Bar) في الواجهة الجديدة RTL.

## 3. عناصر يجب نقلها حرفياً (High-Value UX)

| العنصر | القيمة | القرار للنظام الجديد |
|---|---|---|
| **مخطط الطاولات المرئي بالألوان** | أخضر/أحمر/أزرق/بني | Grid/Flex تفاعلي + أيقونات + تنقيب |
| **Pending KOTs/Bills كنوافذ انتظار** | منع الإغلاق + الوعي الحي | لوحة جانبية حية (Live Pending Panel) |
| **Balance الكبير أثناء التسوية** | منع الحفظ إلا بصفر | عداد بارز ملون (أخضر عند الصفر) |
| **Provisional Bill** | فاتورة بلا رقم للعرض على الضيف | "معاينة قبل الطباعة" |
| **Split بثلاث طرق** | عمليات يومية | معالج تقسيم موحد |
| **Repeat/Modifier التلقائي** | سرعة الإدخال | same |
| **Quick Menu Update فوري/من الغد** | مرونة تشغيلية | خيار سريان صريح |

## 4. نقاط الألم → فرص التحسين

| الألم | الدليل | التحسين |
|---|---|---|
| **إعادة تحميل البرنامج لتفعيل Option 1** | POS-SET §28 ص91 | تحديث فوري بالويب |
| **إعادة الطباعة تُرقِّم من جديد** (تسلسل مكسور) | TS ص41 | تتبع أرقام مرئي + تبرير |
| **الأزرار مجهولة بلا نصوص في الأدلة** | TS (لقطات بلا labels للـ Tool Box) | تسمية عربية واضحة |
| **لا حقل Tips في Cash** | TS ص34 | توحيد خيارات Tips |
| **بحث Guest History التقريبي** معقد | POS-GST §5 | بحث ذكي واحد موحد |
| **قوائم Modifiers بلا أسماء عربية/تسميات RTL** | POS-SET §27 | أولوية التعريب |
| **فصل Regular/Touch/PDA** ثلاث بيئات | POS-SET §20 | منصة واحدة متجاوبة |

## 5. شاشات الوحدة ذات الأولوية للتصميم (P0 UX)

| الشاشة المقترحة | تجمع | الأساس |
|---|---|---|
| **شاشة الطلب (Order Entry) الحية** | TS Order + 4 مستويات + Modifiers + Repeat | TS ص7-22 |
| **مخطط الطاولات التفاعلي** | Table Master + Layout + Booking Status + Pending | POS-SET §12/§39 + LUK |
| **معالج التسوية** | Settle + Split(3) + Link + Tips + Balance | TS ص28-36 |
| **لوحة اليوم (Shift/Outlet)** | Open/Close + المعلقات + Session Statistics | TS ص4-5/46 + LUK §6 |
| **مدير القوائم والأسعار** | Menu Master + Rate/Batch/Quick + نقل المنافذ | POS-SET §24-29 |
| **ملف ضيف المنفذ** | Guest Master 10 تبويبات + Visits + Loyalty | POS-GST |
