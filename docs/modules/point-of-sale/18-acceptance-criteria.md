## خطة اختبار الدخان (Smoke Test)

1. إنشاء منفذ (بدون Standard KOT → يرفض؛ أضفه → ينجح).
2. فتح وردية + منفذ؛ إدخال طلب لطاولة (صنفان بمطبخين → KOT لطابعتين).
3. حذف صنف بلا سبب → يرفض؛ بسبب → ينجح.
4. Promo/Comp لصنف → صفر؛ Check للطاولة → Provisional ثم Print Bill → **تسوية نقدية تلقائية**.
5. فاتورة ثانية: Split Item (Food/Liquor) → فاتورتان؛ تسوية إحداهما CC بالسحب + Tips.
6. فاتورة ثالثة: Guest Settlement بغرفة صحيحة → تظهر بالفوليو وقيود AR؛ بغرفة خاطئة → الضيف لا يظهر.
7. محاولة إغلاق الوردية ومعلقات → يرفض؛ تسوية الكل → الإغلاق ينجح (بكلمة المرور).
8. Resettlement لفاتورة مسوّاة → استفتاء → وضع جديد.
9. Happy Hours متداخلة → يرفض؛ Member Discount لثانوي مع INI 404=1 → يرفض.
10. Reprint قبل التسوية → رقم جديد؛ Pending KOTs/Bills يعرضان الحالة الحية.
