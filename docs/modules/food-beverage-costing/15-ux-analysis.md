# 15 — تحليل تجربة المستخدم (UX Analysis) — وحدة FNB

> UX الوحدة = **عقلية "مولد تقارير بواجهات نموذج ورقي"**: 20 شاشة نتائج بنمط واحد (معايير→Preview→Generate)، وإدخال بالشبكات مع النقر المزدوج واللون — بينما تكمن البراعة في **تدفقات الاختصارات** (F3 قفزة، F7/F8 بحث، Load/Consolidate).

---

## 1. الأنماط التفاعلية الحاكمة

### أ) نمط "مولد التقارير" الصارم (12/13 تقريراً)
- شاشة معايير → زر معاينة → شاشة Preview → زر Generate → التقرير النهائي.
- **الحصيلة**: تنبؤية عالية (المستخدم يعرف مقدمه كل شاشة) ×رتابة بنائية (20 واجهة شبه متطابقة) — أول مرشح في المشروع لـ**شاشة معايير موحدة معاد استخدامها** عند إعادة البناء (wizard واحد بمعايير ديناميكية).

### ب) النقر المزدوج كلغة تحرير (ثالث وحدة بعد MNT/TEL)
| الموضع | الفعل |
|---|---|
| Costing Link: عمود Kitchen Code | تغيير مطبخ المجموعة/الصنف عبر Help |
| Kitchen Opening Stock: صف Green | **فتح إدخال الكمية** (القناة الوحيدة!) |
| Open/Modifiers: عمود Type | اختيار Store Item/Sub Recipe |
| كل النتائج/التقارير | Drill-down التفاصيل |

- **الدلالة**: الوحدة تقرأ أكثر مما تكتب — والكتابة متى احتُاجت **دُفعت إلى أعمدة الشبكة** وليس نماذج مستقلة.

### ج) اللون حالةً (الثالثة بعد POS/MNT)
- **Pink**: المخازن المتاحة عند الجرد (COP ص5) + السجلات المستخرجة بالافتتاحي (COP ص8).
- **Green**: رصيد صفري = **قابل للإدخال** (COP ص8) — اللون هنا ليس تصنيفاً بل **دعوة فعل** (أخضر = اكتب هنا!).

### د) Function Keys كمساحة عمل
- **F1** (مساعدة الأصناف): في 7 شاشات (SET/الجرد/الاستهلاك/الافتتاحي...) — الأكثر حضوراً في المشروع بعد POS.
- **F3**: قفزة Cost Analysis من شبكة الوصفة (SET ص12) — **تنقل سياقي** نادر.
- **F5**: حذف سطر (+تأكيد Yes).
- **F7/F8**: بحث بكود/اسم الصنف (الافتتاحي) — ثنائية بحث نادرة.

## 2. تدفقات الإدخال المقننة

- **تسلسل الصف الورقي**: "Select the Store... Press Enter... The cursor will move to the next column – Item Code" (COP ص5) — الملاحة عمودية حرفية (Enter/أسهم).
- **Grid-First للجرد اليومي**: العدّ آلياً صف أصناف (Store→Item→Qty→Enter→الصف التالي) — عقلية "count sheet".
- **قفزة F3 المطلبية**: بعد "press enter on your keyboard, press F3, the cursor will move to the Cost Analysis Section" — دمج إدخال الوصفة وتحليلها في جلسة واحدة بلا حفظ وسيط.
- **تأكيدات نقطية**: Yes عند Tag Kitchen/Bar (SET ص5) + Yes عند F5 (COP ص6) — تأكيد للحواف الخطرة فقط (لا تأكيد حفظ عام موثق).

## 3. UX التقارير المعيارية

- **نطاقات From/To مكان "multi-select"**: كل التصنيفات نطاقات (Item من-إلى، Group من-إلى، Recipe# من-إلى) — فلسفة era-الاستعلامات النطاقية.
- **XOR دلالي معلن**: ثنائية Consumption Type (Issue↛Restaurant · Recipe↛Kitchen) — الواجهة تحرس المعنى المنهجي (UX كإطار تحليلي!).
- **"No Drill Down Available for this Category"** (LUK ص15): رسالة نهاية شجرة — احترام المستخدم بإخباره الحقيقة بدل زر ميت.
- **80/132 عموداً** (REP ص23): إرث طباعي صريح — يُستبدل بـ responsive HTML.
- **اختيار الطابعة للتشغيل** (Buffet — REP ص27): التقارير تشغيلية أيضاً (مطبخ) لا مكتبية فقط.

## 4. نقاط الألم (Pain Points)

| النقطة | الأثر | الحل عند إعادة البناء |
|---|---|---|
| **إدخال Green بال نقر المزدوج لكل صف** (جرد افتتاحي/مئات الأصناف) | عبء تهيئة ثقيل | جدول قابل للتحرير الشامل (inline grid) + Paste |
| **الجرد اليومي يدوي صرف** (لا scanner/جهاز عد) | أغلى عملية تشغيلية بالوحدة | واجهة موبايل عدّ + استيراد ميزان/باركود |
| **الملاحة العمودية Enter-إلى-العمود-التالي** | بطء موبايل-عصر | Web form بقفزة Tab ذكية |
| **20 شاشة معايير شبه متطابقة** | تعلم متكرر | موحد معايير dynamic |
| **لا حفظ مسودة/حالة مرئية للمعاملات** (كل شيء نهائي من أول حفظ) | قلق الأخطاء (خصوصاً Auto Indent الخالد!) | Draft→Submit workflow |
| **Portion نص** | غير قابل للحساب | حقلان: qty+uom وdescription |
| **فقر رسائل خطأ** (تحذيران فقط في 76 ص) | تجربة صمتة | فراغ معالجة أخطاء يُصمم كاملاً |

## 5. الأصول UX القابلة للنقل (عند إعادة البناء)

1. **اللون كدعوة كتابة** (Green=Enter-here) — نمط فريد يستحق البقاء.
2. **Consolidate في Recipe–Ingredient** — زر تجميع من استعلام مفصل (نمط تحليلي ممتاز).
3. **Link Help داخل Profitability** — المساعد السياقي حيث يحتاجه المحلل.
4. **Preview→Generate** — يبقى بفصل صريح (Configurable Report Builder في Frappe).
5. **رسائل حدود التنقيب الصريحة** — ثقافة "أخبر المستخدم لماذا لا".
