# 15 — تحليل تجربة الاستخدام (UX Analysis) — وحدة TEL

> **طابع "غرفة تشغيل" (Operations Room):** واجهات عامل السنترال الفورية (استعلام لحظي + رسائل صفحة) على الأغلب **حرفية** (أوامر F1/Enter المزدوج) في الشاشات المالية، و**غنية بالأزرار الوظيفية** (Guest Information). نقاط القوة: التلقائية والتاريخ التلقائي والفئات الذكية؛ نقاط الضعف: ازدواج مصطلح Transfer/Extension والنقر المزدوج كأداة حالة.

## 1. أنماط التفاعل الموثقة

| النمط | الموضع | التقييم |
|---|---|---|
| **النقر المزدوج لقلب الحالة** | Select/Tag → YES (Error/Transfer/Messages/Location) | أداة موحدة بلا حماية — نقرتان = ترحيل مالي! |
| **Enter المزدوج** | "hit Enter twice" (View Unbilled) و"press Enter twice" (فتح جدول أسعار Slabs) | اصطلاح تفرقة العرض/التحرير |

| **انتقال المؤشر الذكي** | Room→Room# · Extension→Location | توجيه الإدخال حسب الراديو |
| **راديو متبادل** | Room/Extension · P&T/Guest · By Name/By Room · Transfer/Extension (Stay) | قوائم عرض حصرية |
| **التاريخ التلقائي** | Accounting/System/Today في 6 شاشات | تقليل الخطأ البشري |

## 2. لوحة عامل السنترال (Guest Information) — تقييم تفصيلي

| العنصر | الملاحظة |
|---|---|
| **المدخل الواحد** Name/Room# + F1 | "know the guest's room number... enter... in the Name/Room# field" — حقل مزدوج الغرض (اسم أو غرفة) |
| **أزرار الكشف الأربعة** | Instructions/Complaints/Messages/Location — عقلية "كل شيء عن النزيل في نافذة" — قمة التصميم التشغيلي للعصر |
| **نمط الإبلاغ Tag** | نقر مزدوج → YES → إخفاء من Guest Page Messages — **إدارة قائمة انتظار اتصالات** فعلية (callback list!) |
| **الزر الإداري SL#** | "administrative purposes only... System Administrator" — زر قوة بلا تسمية وظيفية واضحة (تعارض SL#!) |
| **الافتقار:** لا بحث بالاسم الحرفي (فقط Room Help) | الاسم يحتاج النزيل في الغرفة |

## 4. لغة الواجهة (Terminology UX)

### أزمة التسمية المزدوجة (الموثقة) ⚠️

| المصطلح | المعنى 1 | المعنى 2 | المعنى 3 |
|---|---|---|---|
| **Transfer** | تحويل **مكالمة** (CAC/REP) | تحويل **غرفة** (LUK View Transfers) | — |
| **Extension** | الامتداد الهاتفي (كل الوحدة) | **تمديد الإقامة** (View Transfers/Extensions!) | Extension # (رقم الامتداد) |
| **LCA** | كود محلي (شراكة) | — | — |
| **SPL** | نوع مكالمات خاص في تقارير | بلا ماستر! | — |

- **الأثر:** مشغل جديد يفتح View Transfers/Extensions باحثاً عن تحويل مكالمات يجد تحويلات غرف — واسم الخيار الثاني "Extension" يوحي بالامتدادات ويعرض **تمديدات الإقامة**!

## 6. نقاط القوة الموثقة

1. **التلقائية القصوى:** التاريخ/اليوم/الاسم/الموقع auto-populated في كل المواضع الحساسة.
2. **المعاينة قبل الطباعة:** كل التقارير بمرحلتين (شاشة → Print) — حماية ورق.
3. **Page Skip By Extension:** "call details from each extension on a **new page**" — طباعة جاهزة للتوزيع على الأقسام.
4. **الراديو الذاتي التفسير:** All/Specific بكل التقارير.
5. **Yellow Pages الشخصي:** إنتاجية عامل فردي (نادرة في أنظمة ERP تلك الحقبة!).
6. **الحماية الشرطية للحذف:** "works only conditionally" — حذف واعٍ.

## 7. نقاط الضعف الموثقة

1. **النقر المزدوج = فعل مالي** (Select YES) — بلا تأكيد ولا عكس (Undo) موثق.
2. **لا Copy للشريحة** عند الإصدار الجديد — إعادة إدخال 4 أزواج أسعار يدوياً كل تعديل تعرفة!
3. **سجل Bad Record بلا أداة** — عرض فقط.
4. **تعدد الفلاتر المتباعدة:** Error Type في LUK والتقرير REP بلا فلتر — عكس التوقع.
5. **كلمة مرور رقمية ≤10** بلا تعقيد — نمط عتاد EPABX مقبول تقنياً، ضعيف أمنياً.
6. **لا حالة دفعة (Batch):** إعادة ترحيل سطر-بسطر نقراً مزدوجاً.
7. **Call Identifier بلا تحرير:** حذف + إعادة إدخال للتعديل.
