# الأدوات — سكربتات استخراج وفهرسة الأدلة

سكربتات Python لإدارة خط أنابيب المعالجة الأولي للأدلة المصدرية (المحلية فقط — غير مرفوعة للمستودع).

## المتطلبات

```
pip install pymupdf
```

## الاستخدام (بالترتيب)

| السكربت | الوظيفة | المخرجات |
|---|---|---|
| `inventory_manuals.py` | فهرسة ملفات PDF: الميتاداتا + عدد الصفحات + استخراج النصوص كاملة | `extracted-text/` + `inventory.json` |
| `gen_manual_inventory.py` | توليد `docs/analysis/00-discovery/manual-inventory.md` من الفهرس | وثيقة الجرد |
| `extract_tocs.py` | استخراج فهارس المحتويات (TOC) لكل وثيقة (مع معالجة نمط Care المنقّط) | `toc-extracts.json` |
| `extract_fields.py` | مستخرج جداول الحقول الآلي من ملفات الإعدادات (SET) | `field-extracts/*.json` |

> مسار الأدلة المصدرية يُحدَّد داخل كل سكربت (`MANUALS_DIR`). عدّله حسب بيئتك.
> المخرجات كلها مستثناة من Git (انظر `.gitignore`) لأنها مشتقات من محتوى محمي — تُعاد توليدها محلياً عند توفر المصدر.
